                    🌐 ONLINE DEPLOYMENT (BEST)
════════════════════════════════════════════════════════════════════════════════

STEP 1: Firebase Hosting Setup
───────────────────────────────

1. Firebase Console mein jao: https://console.firebase.google.com
2. New Project create karo: "VK-Billing"
3. Project open karo
4. "Hosting" option select karo
5. "Get Started" click karo

Video Reference: Firebase Hosting Setup (YouTube par search karo)


STEP 2: Install Firebase CLI
──────────────────────────────

Windows:
  Download: https://firebase.google.com/download/tools
  Install karo aur restart karo

Mac:
  Terminal mein: brew install firebase-tools

Linux:
  Terminal mein: npm install -g firebase-tools


STEP 3: Deploy Files
─────────────────────

1. Terminal/Command Prompt open karo
2. vk-billing folder mein navigate karo
3. Type karo: firebase login
   (Google account se login karo)

4. Type karo: firebase init hosting
   Project select karo: VK-Billing
   Public folder: . (current folder)
   SPA setup: Yes

5. Files ready karo (wo sabb already hain)

6. Deploy karo: firebase deploy
   
7. ✓ Live URL milega!
   Example: https://vk-billing-xyz.web.app


STEP 4: Access From Anywhere
──────────────────────────────

Desktop: https://vk-billing-xyz.web.app
Mobile:  https://vk-billing-xyz.web.app
Offline: App ke liye "Install" button milega

════════════════════════════════════════════════════════════════════════════════
                    ❌ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

PROBLEM: Logo nahi dikh raha

Solution:
- icon-192.png check karo same folder mein
- Filename exactly "icon-192.png" hona chahiye
- "-1" suffix remove karo agar hai


PROBLEM: App slow chal raha hai

Solution:
- Browser cache clear karo (Ctrl+Shift+Delete)
- Hard refresh karo (Ctrl+Shift+R)
- Service worker restart karo


PROBLEM: Firebase error

Solution:
- Firebase keys check karo config mein
- Internet connection check karo
- Firebase project active hai check karo


PROBLEM: Split payment nahi dikha

Solution:
- Page reload karo
- Browser cache clear karo
- Tab refresh karo (Ctrl+R)


PROBLEM: Offline nahi chal raha

Solution:
- HTTPS chahiye (localhost: OK hai)
- Service worker register ho sakha hai check karo (DevTools)
- Manifest file present hai check karo


PROBLEM: Ek device se dusre device mein access nahi

Solution:
- Local use karta ho to network mein ho same
- Online deployment chahiye
- Firebase hosting pe deploy karo
