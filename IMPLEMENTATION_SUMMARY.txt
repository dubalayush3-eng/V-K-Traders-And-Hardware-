✅ FEATURES ADDED:

1️⃣  SPLIT PAYMENT MODE
   • New payment mode: "Split" (UPI + Cash combination)
   • Cycle through: Cash → UPI → Split (F8 key)
   • Real-time amount validation
   • Prevents saving if amounts don't match total

2️⃣  UPI CONFIRMATION WITH UTR
   • UTR (Unique Transaction Reference) input field
   • Automatic 12-16 character validation
   • Verify button for confirmation
   • UTR saved in database with timestamp

3️⃣  DATABASE STORAGE
   • Split payment data stored as separate object
   • Contains: mode, upiAmount, cashAmount, upiUtr, verificationTime
   • Backward compatible with existing bill records

4️⃣  UI/UX IMPROVEMENTS
   • Dynamic payment mode tabs (💵 🔀 📱)
   • Split amount inputs with real-time totals
   • Golden-themed UTR section
   • Mobile responsive design
   • Dark/Light theme support

═══════════════════════════════════════════════════════════════════════════════

🎯 HOW TO USE:

Step 1: Select Split Mode
  └─ Click "🔀 Split" button OR press F8 until Split mode shows

Step 2: Enter Amounts
  ├─ UPI Amount: Enter amount paid via UPI
  └─ Cash Amount: Rest of the amount will be cash
      ⚠️  Total must equal bill amount

Step 3: Verify UTR
  ├─ Enter UTR from bank app
  ├─ Click "Verify UTR" button
  └─ ✓ Shows when verified

Step 4: Save Bill
  ├─ Click Save button
  └─ Bill saved with all split payment details
