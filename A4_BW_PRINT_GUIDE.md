                      HOW TO PRINT (STEP BY STEP)
════════════════════════════════════════════════════════════════════════════════

MOBILE SE PRINT KARNA:

Step 1: Bill Complete Karo
────────────────────────────
• Sabb items add karo
• Customer details enter karo
• Discount/Tax set karo
• Payment mode select karo
• Total check karo

Step 2: Print Button Click Karo
────────────────────────────────
• Bottom mein "Print A4" button dikhe
• Click karo
• Or: Top-right share → Print

Step 3: Print Dialog Open Hoga
────────────────────────────────
• Printer select karo (local printer)
• Paper size: A4 select karo
• Margins: Default (8mm)
• Color: B&W (Black & White) select karo
• Copies: 1 (ya jitne chahiye)

Step 4: Print Button Press Karo
────────────────────────────────
• "Print" button click karo
• Printer shuru ho jaega
• Wait for bill print hona


DESKTOP/LAPTOP SE PRINT KARNA:

Step 1: Browser mein App Open Karo
───────────────────────────────────
• Chrome/Firefox mein app open karo
• Bill complete karo

Step 2: Print Button Click Karo
────────────────────────────────
• "Print A4" button click karo
• Or: Ctrl+P (Windows) / Cmd+P (Mac)

Step 3: Print Settings
──────────────────────
• Destination: Select printer
• Paper size: A4
• Orientation: Portrait
• Margins: Default
• Color mode: B&W / Grayscale
• Headers/Footers: OFF

Step 4: Print
─────────────
• "Print" button click karo
• Done!

════════════════════════════════════════════════════════════════════════════════
                      TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

PROBLEM 1: Colors printing instead of B&W
──────────────────────────────────────────
SOLUTION:
• Printer settings check karo
• "Black & White" mode select karo
• Or: "Grayscale" select karo
• Printer preferences mein toner save mode check karo

PROBLEM 2: Text cutoff ho rahi hai
──────────────────────────────────
SOLUTION:
• Print dialog mein scaling 100% set karo
• Margins default rakho (8mm)
• Paper size A4 confirm karo
• Portrait orientation select karo

PROBLEM 3: Page breaks galat jagah ho rahe hain
───────────────────────────────────────────────
SOLUTION:
• Print preview check karo
• Margins adjust karo
• Scaling adjust kar sakte ho
• Alag alag settings try karo

PROBLEM 4: Print button nahi dikh raha
──────────────────────────────────────
SOLUTION:
• Page bottom scroll karo
• "Print A4" button find karo
• Ya keyboard: Ctrl+P (Windows) / Cmd+P (Mac)

PROBLEM 5: Quality kharab hai
────────────────────────────
SOLUTION:
• Printer cartridge check karo
• Toner density increase karo
• Quality setting "High" set karo
• Acha paper use karo
