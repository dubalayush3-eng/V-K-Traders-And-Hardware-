CREATE BACKUP:

Manual Backup
─────────────
1. Settings tab
2. "Backup Management" section
3. Click "📥 Create Backup Now"
4. Wait for completion
5. ✅ Backup created!
6. Shows in "Recent Backups" list


AUTO BACKUP SETUP:
──────────────────
1. Settings tab
2. Check "Enable automatic daily backups"
3. System creates backup every 24 hours
4. Runs in background
5. No action needed!


DOWNLOAD BACKUP:

Step 1: Go to Backups
──────────────────
1. Settings tab
2. "Recent Backups" section
3. See all backups with dates

Step 2: Download
────────────────
1. Click "Download" button next to backup
2. Choose save location
3. File: vk_billing_backup_[timestamp].json
4. File size shown (KB)

Step 3: Store Safely
────────────────────
• Save on cloud (Google Drive, Dropbox)
• Save on external storage
• Keep multiple copies
• Keep secure location


RESTORE BACKUP:

Step 1: Select Restore File
────────────────────────────
1. Settings tab
2. Click "📤 Restore from File"
3. Choose backup file (.json)

Step 2: Confirm Restore
────────────────────────
1. Confirm you want to restore
2. ⚠️ This will replace current data
3. Click Restore

Step 3: App Reloads
──────────────────
1. Page automatically reloads
2. Old data replaced with backup data
3. ✅ Ready to use!


EXPORT DATA:

To JSON (Technical Backup):
──────────────────────────

BACKUP SCHEDULE:

Daily Backups (if enabled):
──────────────────────────
• 12:00 AM (midnight): Daily backup
• Automatic download
• Previous backup kept as version

Manual Backups:
───────────────
• Create anytime
• Keep multiple versions
• Different dates available

Cloud Sync:
───────────
• Firebase syncs automatically
• Real-time backup
• Accessible from any device


BACKUP BEST PRACTICES:

✅ DO:
• Create backup before major changes
• Download backup weekly minimum
• Store backup in 2 locations
• Test restore monthly
• Document backup locations
• Keep password secure

❌ DON'T:
• Rely on single backup
• Store backup on same device
• Share backup file with others
• Forget to backup regularly
• Delete backups unnecessarily


RECOVERY SCENARIOS:

Lost Data:
──────────
1. Download latest backup
2. Settings → Restore from File
3. Select backup file
4. Data restored! ✅

Device Crash:
──────────────
1. Use cloud backup (Firebase)
2. Login on new device
3. All data synced automatically
4. No data loss!

Accidental Deletion:
───────────────────
1. Find backup before deletion date
2. Restore that backup
3. Only that time period lost
4. Recent data lost

File Corrupted:
───────────────
1. Try next day's backup
2. If all corrupted, restore from cloud
3. Rare, but backup exists!

                      TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

LOGIN ISSUES:

Can't Login:
────────────
1. Check username: admin (case-sensitive)
2. Check password: admin123
3. Clear browser cache
4. Try incognito tab
5. Check internet connection

Stuck on Login Screen:
───────────────────
1. Refresh page
2. Clear cache and cookies
3. Close and reopen browser
4. Try different browser


BACKUP ISSUES:

Backup Won't Create:
───────────────────
1. Check available storage
2. Check internet connection
3. Clear browser cache
4. Try manual backup

Restore Failed:
────────────────
1. Check file format (.json)
2. File not corrupted
3. Try different browser
4. Contact support


PRINTING ISSUES:

Print Dialog Not Opening:
─────────────────────────
1. Check pop-up blocker
2. Allow pop-ups for this site
3. Clear browser cache
4. Use different printer

Print Quality Bad:
──────────────────
1. Check print settings
2. Select "High Quality"
3. Check toner/ink level
4. Use proper paper


AUDIT LOG ISSUES:

Log Not Recording:
──────────────────
1. Check browser storage enabled
2. Clear full cache
3. Logout and login again
4. Check console for errors
